# DiyVod  安卓播放器  Personal Video CmsPlayer
DiyVod 手机版
Android 手机 / 平板 · 触控操作
手机版适合日常随身播放和资源管理。界面以触摸操作为主，集成播放、搜索、选集、接口管理、API 管理、订阅和网页入口等功能。

✓
播放控制：播放/暂停、快进快退、倍速、静音、循环、全屏等。
✓
选集与线路：支持线路切换、剧集选择和连续播放。
✓
接口 / API / 订阅：支持资源接口管理、收藏、测速和订阅使用。
✓
搜索：可通过当前资源接口搜索并播放返回的影视内容。
✓
需求：适用于安卓8.0以上系统使用
手机版适合经常需要搜索、选集、接口切换和订阅管理的用户。

DiyVod TV版
Android TV / 电视盒子 · 遥控器操作
TV版针对横屏、大字号、电视遥控器和客厅使用场景设计，并通过手机局域网页面辅助处理电视端不方便输入的操作。

✓
电视大屏：分类导航、海报展示、详情、线路与选集针对大屏设计。
✓
遥控器优化：方向键、确定、返回、单击/长按快进快退。
✓
剧集播放：上一集、下一集、当前集结束自动播放下一集。
✓
手机辅助：同一局域网可通过手机网页辅助搜索、配置和管理。
✓
安全锁：加入儿童安全锁，您的隐私陪护儿童绿色成长
TV版建议安装于 Android TV、智能电视或电视盒子，适用于安卓8.0以上系统使用。
